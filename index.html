Deploy to GitHub Pages

Host this tracker completely free in 3 quick steps

1

Create a new repository on GitHub (e.g., daily-tracker).

2

Create a file named index.html in the repository root and paste this entire code file into it.

3

Go to repository Settings → Pages. Under Build and deployment → Branch, select main (or master) and folder / (root), then click Save.
